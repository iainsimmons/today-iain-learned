## Intro

This is a list of the things I'm currently using for work and play. Mostly inspired by [Wes Bos' own /uses page](https://wesbos.com/uses). See [Slash Pages](https://slashpages.net/) for more of this kind of thing.

## Coding

- [Neovim](https://neovim.io/) has been my go-to text editor since 
- [Ghostty]
- [WezTerm](https://wezfurlong.org/wezterm/): terminal emulator
    
- [tmux](https://github.com/tmux/tmux): terminal multiplexer

    
- [fish](https://fishshell.com/): shell
    
- [sesh](https://github.com/joshmedeski/sesh): tmux plugin for quickly switching sessions
    
- [Yazi](https://yazi-rs.github.io/): file explorer TUI
    
- [tinted-theming](https://github.com/tinted-theming/home): base16 colorschemes fork for all the things
    
- [fzf](https://github.com/junegunn/fzf): fuzzy finder and [fzf.fish](https://github.com/PatrickF1/fzf.fish) fzf plugin for fish shell
    
- [zoxide](https://github.com/ajeetdsouza/zoxide): A smarter cd command
    
- [atuin](https://atuin.sh/): magical shell history
    
- [ov](https://noborus.github.io/ov/index.html): pager
    
- [fnm](https://github.com/Schniz/fnm): Fast and simple Node.js version manager
    
- [fx](https://fx.wtf/): JSON viewer & processor TUI
    
- [posting](https://posting.sh/): REST API client TUI
    
- [Raycast](https://www.raycast.com/): launcher, shortcuts, window management, converter and more
    
- [Obsidian](https://obsidian.md/): notes
    
- [Shottr](https://shottr.cc/): screenshot tool
    
- [Lazygit](https://github.com/jesseduffield/lazygit): simple terminal UI for git commands
